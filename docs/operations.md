# 店員操作手冊

## 開店準備

1. 讓櫃台裝置與客人手機連上可存取樹莓派的店內 Wi-Fi。
2. 用店家密碼登入 [店家後台](http://192.168.8.235:8083/admin)。第一次登入時，請管理者依[部署與維護手冊](deployment.md#店家密碼)取得密碼。
3. 在後台按「開啟提示音」，並保持頁面開啟。頁面約每三秒更新，新訂單與結帳請求會顯示桌號並播放提示音。重新開啟後台時，確認按鈕顯示「關閉提示音」。

## 列印六張桌牌

1. 登入後開啟[桌牌 QR Code](http://192.168.8.235:8083/admin/qr)。確認點餐網址是客人手機能開啟的店內網址，目前為 `http://192.168.8.235:8083`。
2. 按「列印六張桌牌」，在列印視窗選擇 A4。按第 1 桌到第 6 桌的標示裁切並擺放。
3. 在店內 Wi-Fi 用手機掃描每張桌牌，確認頁面桌號、餐點和照片。更改店內網址後須重印。

## 點餐與收款

1. 客人掃描桌牌，選好餐點後開啟購物車，填寫所需備註，再按「送出訂單」。同一桌可以分次送單，所有未結帳訂單會列在「本桌帳單」。
2. 店員在後台的「桌況」展開訂單，查看餐點、份數與備註。客人按「通知店員結帳」後，該桌會顯示「請求結帳」。
3. 店員現場向客人收款，再在該桌按「登記收款」，核對金額並按「已收款，完成結帳」。若確認時有新餐點送入，後台會要求先核對更新後的帳單。
4. 收款確認後，該桌的待結帳帳單會清空，後台保留已結帳的訂單紀錄。

「今日訂單」按送單時間顯示。「已結帳金額」按實際確認收款的時間計入今日、本月和今年，均以台灣時間計算。前一天送出的未結帳單仍可在「桌況」查看。

## 常見狀況

| 狀況 | 處理方式 |
| --- | --- |
| 手機掃碼後開不了菜單 | 確認手機已連上店內 Wi-Fi，且可以開啟 [點餐首頁](http://192.168.8.235:8083/)。若首頁可開啟，再核對桌牌是否為目前店內網址。 |
| 點餐頁的桌號與實際桌次不符 | 暫停使用該桌牌，比對頁面和紙本桌號，再調整桌牌位置。 |
| 後台有提醒但沒有聲音 | 確認已開啟提示音，並檢查系統音量及網頁是否靜音。 |
| 後台顯示連線中斷 | 確認櫃台裝置仍連著店內 Wi-Fi。若首頁也無法開啟，請管理者依[故障排查](deployment.md#故障排查)檢查服務。 |
